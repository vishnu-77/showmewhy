# Security Policy

## Supported versions

During private preview, only the latest version on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

While the repository is private, report security findings directly to the repository owner through GitHub. Include:

- affected version or commit;
- reproduction steps;
- security impact;
- any suggested mitigation.

Do not include credentials, tokens, private prompts, user data, or other secrets in reports.

## Security-sensitive behaviour

ShowMeWhy must not present generated provenance, confidence, risk, token, energy, or carbon values as measured facts unless the underlying measurement exists. Evidence references should point to observable artefacts rather than hidden model reasoning.
